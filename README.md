# tims-lab1

Лабораторна робота №1 з дисципліни «Теорія ймовірностей та математична статистика»

**Тема:** Побудова дискретних варіаційних рядів. Розрахунок їх характеристик

**Викладач:** Кобзєв В. Г.

**Набори даних:** В16 (таблиця n = 20) та №17 (таблиця n = 100)

## Автор

- **Коновалов Олександр**, група ПЗПІ-25-6, oleksandr.konovalov1@nure.ua

## Мета роботи

Вивчення та застосування дискретних варіаційних рядів під час розв'язання задач математичної статистики. Розрахунок характеристик варіаційних рядів з використанням програмних засобів.

## Вимоги

Джерело: методичка `ТЙМС_Лаб1н ПОБУДОВА ДИСКРЕТНИХ ВАРІАЦІЙНИХ РЯДІВ`, п. 1.3. Для кожного набору окремо:

- [x] побудувати варіаційний ряд значень випадкової величини;
- [x] побудувати дискретні варіаційні ряди розподілу частот, відносних частот, накопичених частот, накопичених відносних частот;
- [x] побудувати багатокутник та емпіричну функцію розподілу;
- [x] обчислити середнє арифметичне, моду, медіану, середнє лінійне відхилення, дисперсію, коефіцієнти асиметрії та ексцесу.

Звіт: титульний аркуш, мета, номер варіанта та екранна копія вихідних даних, хід виконання для кожного набору з формулами, фрагментами коду й результатами, висновки про характер розподілу.

## Технології

- TypeScript (Node.js, `tsx`) — обчислення без сторонніх статистичних бібліотек, за формулами (1.1)–(1.6) з методички
- `@resvg/resvg-js` — рендеринг графіків (SVG → PNG)
- `docx` — генерація звіту

## Запуск

```bash
npm install
npm start        # таблиці частот, характеристики, графіки в reports/lr1/figures/
npm test         # перевірка формул на прикладах, обчислених вручну
npm run report   # DOCX-звіт
```

## Структура

```
src/
├── data.ts         # вихідні набори В16 та №17
├── stats.ts        # варіаційний ряд, таблиця частот, F*(x), числові характеристики
├── charts.ts       # багатокутник частот і емпірична функція розподілу
├── main.ts         # точка входу
└── stats.test.ts   # тести
reports/lr1/
├── figures/        # графіки, згенеровані npm start

```
